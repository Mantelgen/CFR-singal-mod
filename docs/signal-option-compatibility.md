# Signal option compatibility

The configuration editor filters its choices by signal family. The same rules
run on saved data and incoming packets, so an invalid combination cannot be
created by an old world or a modified client.

| Family | Physical mount | Finishes | Auxiliary display | Other rules |
| --- | --- | --- | --- | --- |
| Two-light | Mast top, continuous-pole inline, signal bridge, or wall | Classic, modern grey | All displays | One independently controlled head |
| Three-light | Mast top, continuous-pole inline, signal bridge, or wall | Classic, modern grey | All displays | One independently controlled head |
| Shunting | Mast top, continuous-pole inline, signal bridge, or wall | Classic, modern grey | Direction, track, left-track | Wall form omits mast-only ladder and cabinet |
| Repeater | Mast top, continuous-pole inline, signal bridge, or wall | Classic, modern grey | None | Uses its own luminous bar display |
| TMV modular | Mast top, continuous-pole inline, signal bridge, or wall | Classic, modern grey | All displays | Speed and next-speed panels are supported |
| Emergency diamond | Mast top, continuous-pole inline, or signal bridge | Classic, modern grey | None | Fixed centered head |
| Legacy dwarf entry | Base + pole(s) + head | Classic | None | Fixed centered head on the shared physical assembly |
| Mechanical semaphore | Mast top, continuous-pole inline, or signal bridge | Classic | None | Fixed arm mounting above the bridge beam |

The matrix follows the functional separation in Romanian Regulation 004:
circulation, shunting, repeater, and emergency signals are distinct families;
blue and lunar-white are the shunting aspects; speed, direction, line, and
short-distance displays supplement compatible luminous circulation signals.
Each head owns one Create signal link. Place separate assembled signals for
separate tracks so every head can show its own aspect. All families use the same
validated vertical support: one base, 1–12 aligned pole blocks, then the head.
Ladders and the electrical cabinet are physical, mandatory mast model parts
rather than optional configuration attachments. Wall-mounted electric heads
instead require a solid block immediately behind the head and use dedicated
head and identification-plate brackets.

For a signal bridge, place a bridge beam directly on the top pole and extend it
perpendicular to the signal-facing direction. One-sided beams make an L-shaped
cantilever; beams extending to both sides make a T-shaped bridge. A luminous
head goes directly below a beam, while a mechanical semaphore goes directly
above it. The head must use the beam's facing and find an aligned pole/base
support through no more than eight contiguous beam blocks. Multiple heads may
use one bridge, and each remains an independent Create signal.

The **Inline continuous pole** mount replaces one pole segment with the signal
controller. It requires aligned pole blocks below and directly above the head,
renders a matching mast-and-ladder segment through the head block, and follows
the column down through any lower inline heads to the CFR signal base. Several
heads can therefore occupy different heights in one uninterrupted pole column
while retaining separate Create track links.
